# Best Courses Ever

Best Courses Ever — это образовательная платформа, позволяющая пользователям создавать, редактировать и просматривать курсы, содержащие медиа-контент. Платформа включает в себя систему ролей (пользователь, администратор, автор) и поддерживает комментирование и оценку курсов и занятий.

## Основные функции

- Создание и редактирование курсов и занятий.
- Просмотр курсов и занятий, включая видео, ссылки и файлы.
- Комментирование и оценка курсов и занятий.
- Управление доступом к курсам.
- Возможность логина и логаута.
- REST API для управления ресурсами приложения.
- Поиск по курсам и занятиям.

## Технологии

- Backend: Node.js, Express.js
- Database: PostgreSQL
- Authentication: JWT
- API: RESTful

## Установка

1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/yourusername/best-courses-ever.git
    ```

2. Установите зависимости:
    ```bash
    cd best-courses-ever
    npm install
    ```

3. Настройте переменные окружения:
    ```bash
    cp .env.example .env
    ```

4. Запустите сервер:
    ```bash
    npm start
    ```

## API

Документация по API доступна по адресу `/api-docs` после запуска сервера.
